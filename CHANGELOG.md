# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Версию поднимаем в `package.json` и `package-lock.json` в том же PR, что меняет приложение (CI это проверяет): исправление → PATCH, функция → MINOR, несовместимое изменение → MAJOR. Версия показывается в «Настройки → О приложении».

## [Не выпущено]

## [1.1.2] — 2026-11-04

### Изменено
- Форма быстрого добавления на низких экранах (≤ 640 px): дата — компактный чип с областью нажатия 44 px, «Исключить из дней без трат» убрано под кнопку «Ещё» (отметка-точка, если включено), счёт в одну строку, подсказка-градиент, когда ниже есть ещё категории. На 360×640 видно две полные строки категорий вместо одной. (#34)

## [1.1.1] — 2026-11-04

### Исправлено
- Расход и доход нельзя сохранить без категории (форма «+» и сервис): суммы по категориям в «Бюджете» больше не расходятся с общим итогом. Для ранее созданных операций без категории в «Бюджете» показывается строка «Без категории». (#27)

### Изменено
- CI проверяет, что в PR с изменениями приложения версия повышена по SemVer и есть запись в журнале изменений.

## [1.1.0] — 2026-11-04

### Добавлено
- Публикация на GitHub Pages.
- Настройки перенесены в шестерёнку в шапке, нижняя навигация из 4 вкладок с центральной «+».
- Раздел «О приложении»: версия, дата сборки, коммит, режим, размер экрана.
- Курсы валют из собственного архива курсов Нацбанка РК (`nbk-rates`).
- Предложение установить приложение сразу при открытии.
- Иконка и доработки для iOS (режим приложения, безопасные зоны, поля 16 px).

### Исправлено
- Уведомление об обновлении появляется без полной перезагрузки (проверка при возврате в приложение).
- Читаемость текста и цифровая клавиатура всегда на экране в быстром добавлении.
- Крупный заголовок страницы, ограниченный нижний отступ.
- Нижняя панель «парила» после холодного запуска на iOS.

## [1.0.0] — 2026-11-04

Первый релиз: счета, быстрый ввод, дашборд, планирование бюджета, цели, долги, челлендж «дни без трат», аналитика, трёхуровневое резервное копирование, PWA с офлайн-режимом.
